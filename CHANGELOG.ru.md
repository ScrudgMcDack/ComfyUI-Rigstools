# История изменений

<p align="center"><a href="CHANGELOG.md">English</a> · <b>Русский</b></p>

Заметные изменения Rigstools. Версии нумеруются по [семантическому версионированию](https://semver.org/lang/ru/).

## [1.1.0] — 2026-11-14
### Добавлено
- **Color correction — режим auto:** новый переключатель `mode` (manual / auto). В режиме auto нода измеряет каждую
  картинку и сама выбирает силу баланса белого, уровней и вибранса и небольшую поправку экспозиции; эти три ползунка
  тогда неактивны. При включённом Debug измеренные значения и выбранные силы выводятся в консоль.

### Изменено
- Color correction: `mode` — первая настройка ноды. Workflow, сохранённые в 1.0.0, открываются в режиме manual, все
  значения на своих местах.
- Save image: переключатель Preference (File / Graph / Input) — тем же шрифтом, той же высоты и с теми же углами, что
  поля блока, правый край выровнен по ним, три ячейки одинаковой ширины.

### Документация
- README: раздел Nodes 2.0 — новый вид нод пока не поддерживается, поддержка запланирована в следующем мажорном
  обновлении.
- README: картинка Color correction в режиме auto, новые скриншоты загрузчика и Save image.

## [1.0.0] — 2026-11-12
Первая публичная версия.
- **Load image with metadata**, **Load image with parameters**, **Load image from folder** — загрузка картинок (PNG,
  JPEG, WebP) с данными генерации; параметры — отдельными выходами, видны и редактируются прямо под картинкой.
- **Metadata extractor**, **Parameters extractor** — разбирают метаданные и параметры в формате A1111 на выходы.
- **LoRA hashes for Image Saver** — строка `additional_hashes` для Image Saver из стека LoRA.
- **Save image** — сохраняет картинки с данными генерации, которые сама собирает из графа; параметры и хэши, понятные
  Civitai, предпросмотр того, что будет записано, переключатель Preference (File / Graph / Input).
- **Color correction** — автоматическая цветокоррекция без нейросетей: баланс белого, уровни, вибранс, подгонка под
  образец, ручные поправки, гистограмма.
- Отметки и подсказки на выходах; интерфейс на русском и английском; настройка Debug для лога в консоли.
