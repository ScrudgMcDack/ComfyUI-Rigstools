# История изменений

<p align="center"><a href="CHANGELOG.md">English</a> · <b>Русский</b></p>

Заметные изменения Rigstools. Версии нумеруются по [семантическому версионированию](https://semver.org/lang/ru/).

## [2.0.1] — 2026-11-21
### Добавлено
- PicoTeka: **Shift + Delete** (или Shift + щелчок по кнопке «Удалить») удаляет картинки безвозвратно, минуя корзину, —
  после предупреждения; в нём по умолчанию выбрана «Отмена», так что случайный Enter ничего не удалит.

### Изменено
- PicoTeka: в окне удаления появилась кнопка **Отмена**, а вместо «корзины Windows» теперь «корзина ОС»; у всех кнопок
  «Удалить» красная рамка; у «Данных файла» зелёный значок (i).

### Исправлено
- Баннер README: надписи стоят симметрично относительно реторты; у реестра Comfy и ComfyUI-Manager теперь свой
  баннер (21:9).
- PicoTeka: «Вписать», «Параметры», «Рядом / Шторка» и вкладки «Данных файла» больше не становятся шире, когда
  включены, и соседние кнопки не сдвигаются.

## [2.0.0] — 2026-11-21
### Добавлено
- **PicoTeka** — быстрая и простая галерея для сгенерированных картинок, открывается кнопкой на верхней панели
  ComfyUI (в своей вкладке браузера): дерево папок (папка output и любые добавленные — их выбирают в обзоре папок;
  Ctrl + щелчок показывает сразу несколько), поиск по промпту и имени файла, фильтры по модели, LoRA, сэмплеру, тегу,
  рейтингу и дате, карточка со всеми параметрами.
- PicoTeka: индекс обновляется сам — галерея проверяет папки после каждой завершённой генерации, куда бы ни
  сохранилась картинка, а открытая страница ещё и сама раз в несколько секунд ищет картинки, добавленные не через
  ComfyUI. Новые картинки встают в сетку без перезагрузки и ненадолго подсвечиваются; сетка не прыгает — картинки,
  которые сдвинули бы ряды у вас перед глазами, ждут за полосой **Новых картинок: N ↑**.
- PicoTeka: **теги** с автоматическими цветами (переименование, слияние, удаление), **рейтинг** 0–5, **удаление** в
  корзину (теги и рейтинг хранятся 30 дней) и **перемещение** в другую папку — для одной картинки или для выбранных
  (Ctrl + щелчок, Shift + щелчок; Esc или щелчок по пустому месту снимает выбор); на всё есть клавиши.
- PicoTeka: полноэкранный **просмотр** с масштабом, миникартой и панелью параметров и **сравнение** двух картинок —
  рядом или со шторкой, с метками A и B у имён и таблицей параметров с подсветкой различий. У обоих одинаковые клавиши
  (+ / − — масштаб, Ctrl + 0 — вписать) и подсказки по мыши и клавишам за значком **?**.
- PicoTeka → workflow: **Картинку в workflow** (в Load image with parameters / with metadata), **Параметры в
  workflow** и **Открыть workflow** — во вкладку ComfyUI, с которой работали последней; если подходящих нод несколько —
  список для выбора, если нет ни одной — предложение добавить.
- **Generation parameters** — новая нода, которая хранит параметры без картинки (заполняется из PicoTeka), с той же
  панелью, что у загрузчиков, и теми же выходами, что у Parameters extractor.
- Настройки **Rigstools → PicoTeka**: использовать галерею (по умолчанию включено; выключено — нет кнопки и
  индексации), автообновление открытой галереи (по умолчанию 10 с; 30 с, 60 с или выкл) и разрешить удаление и
  перемещение файлов, когда галерея открыта с другого компьютера (по умолчанию выключено).

### Изменено
- Новая зависимость: `send2trash` (удаление в корзину).

### Документация
- README переписан: баннер, зачем появился Rigstools, обзор «Что внутри», раздел PicoTeka с новыми скриншотами,
  настройки списком; поддержка Nodes 2.0 запланирована в одной из следующих версий.

## [1.1.0] — 2026-11-14
### Добавлено
- **Color correction — режим auto:** новый переключатель `mode` (manual / auto). В режиме auto нода измеряет каждую
  картинку и сама выбирает силу баланса белого, уровней и вибранса и небольшую поправку экспозиции; эти три ползунка
  тогда неактивны. При включённом Debug измеренные значения и выбранные силы выводятся в консоль.

### Изменено
- Color correction: `mode` — первая настройка ноды. Workflow, сохранённые в 1.0.0, открываются в режиме manual, все
  значения на своих местах.
- Save image: переключатель Preference (File / Graph / Input) — тем же шрифтом, той же высоты и с теми же углами, что
  поля блока, правый край выровнен по ним, три ячейки одинаковой ширины.

### Документация
- README: раздел Nodes 2.0 — новый вид нод пока не поддерживается, поддержка запланирована в следующем мажорном
  обновлении.
- README: картинка Color correction в режиме auto, новые скриншоты загрузчика и Save image.

## [1.0.0] — 2026-11-12
Первая публичная версия.
- **Load image with metadata**, **Load image with parameters**, **Load image from folder** — загрузка картинок (PNG,
  JPEG, WebP) с данными генерации; параметры — отдельными выходами, видны и редактируются прямо под картинкой.
- **Metadata extractor**, **Parameters extractor** — разбирают метаданные и параметры в формате A1111 на выходы.
- **LoRA hashes for Image Saver** — строка `additional_hashes` для Image Saver из стека LoRA.
- **Save image** — сохраняет картинки с данными генерации, которые сама собирает из графа; параметры и хэши, понятные
  Civitai, предпросмотр того, что будет записано, переключатель Preference (File / Graph / Input).
- **Color correction** — автоматическая цветокоррекция без нейросетей: баланс белого, уровни, вибранс, подгонка под
  образец, ручные поправки, гистограмма.
- Отметки и подсказки на выходах; интерфейс на русском и английском; настройка Debug для лога в консоли.
